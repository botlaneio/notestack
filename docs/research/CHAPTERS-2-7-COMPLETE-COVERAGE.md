## Assessment boundaries

- Numeric expressions use a restricted arithmetic parser for fractions, powers and square roots, with no dynamic code execution. Exact expressions are encouraged; a small floating-point comparison tolerance accommodates equivalent forms.
- Written arguments, symbolic derivations, classifications and graph constructions are not automatically marked correct. Draft submission, viewing a worked model and checking its requirements record self-review. Teacher verification remains pending.
- Graph constructions have a coordinate pad with equal axis scales; plotted points save per question. It does not verify a proof or graph, and it does not record a drawing as mastered.
- Optional Exercise 5.4 remains labelled optional. External section division is identified as higher-class context rather than an assessed topic.
- Every numbered worked example has its own practice activity. Theorems 6.1–6.5 include proof models. Cubic relationships include all three coefficient identities.
- Legacy guided position maps by the original question ID. Completing an old pilot does not complete newly inserted checkpoints. Answers, hint use and retry history are retained.
