# Maths and Science source-item index

Page references use the chapter sequence in the supplied edition. PDF page numbers are one-based. Multipart Science uploads and the two Maths parts restart their numbering; chapter-opening footers sometimes retain another edition’s numbering.

Each identifier is listed with the pages where it occurs in the source, including references in prose. Unmarked workbook IDs match text in a reference, prompt or model solution. Entries marked “context” identify the exercise, worked example or related guided concept by the surrounding source passage. A concept can cover the method while using different names, data or diagrams. Science 1–5 figure rows also identify the practice task that discusses the principle and the feature to inspect on the printed figure. Some tasks explain only part of a figure. A dash calls for a semantic or visual match. A matched ID alone establishes neither diagram fidelity nor correctness of the answer.
