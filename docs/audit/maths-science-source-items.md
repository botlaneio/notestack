# Maths and Science source-item index

Page references use the chapter sequence in the supplied edition. PDF page numbers are one-based. Multipart Science uploads and the two Maths parts restart their numbering; chapter-opening footers sometimes retain another edition’s numbering.

Each identifier is listed with the pages where it occurs in the source, including references in prose. Workbook IDs are direct text matches in the reference, prompt or model solution. A dash calls for a semantic or visual match. A matched ID alone establishes neither diagram fidelity nor correctness of the answer.
