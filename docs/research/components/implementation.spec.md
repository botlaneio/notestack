# Enhanced homepage specification
Status: implemented; visual comparison blocked by browser runtime.
Original exact computed values are unavailable. Values below are deliberate redesign choices, not extracted measurements.

## Header
Announcement, source logo, Astryx search and bag/wishlist controls, category navigation. White background; 1280px max content; desktop 99px masthead and 52px nav. Mobile 119px two-row masthead and click-toggle nav. Search filters sample-paper catalog; Enter scrolls to results.

## Hero
Split copy and actual three-book arrangement. Navy 57px desktop / 38px mobile heading, off-white copy field, pale green book stage. 440px desktop minimum; stacked on mobile. Primary CTA scrolls to class picker. Secondary opens Class 10 shelf. No invented performance figures.

## Benefits / class picker / collections
Four service items, twelve class choices, four category paths. Class selection changes shelf context; Class 10 sample papers render locally, other categories link to source. Four columns desktop, two mobile; class chips six per mobile row. Selected class has red border and pale red fill.

## Catalog
Four-column desktop/two-column mobile grid; local source covers; edition label; saved toggle; view dialog; title/description/price; Astryx add action. Subject buttons and search combine; saved-only view supported; empty state resets. Product state preserves year, price and API availability. Covers raise 5px on hover, 250ms; quick-view enters 200ms. Reduced motion disables transitions.

## Promotions / resources / feedback
Two flat collection promotions; three practical study notes; two summarised source testimonials clearly attributed as summaries. No stock photography or generated claims. Mobile stacks sections. Closing action returns to catalog.

## Footer / overlays
Source store, category, contact and policy links. Local bag with quantities and original product purchase links. Native dialog supports Escape and close, modal backdrop; status toast announces additions. Cart and saved choices persist in localStorage. No checkout, account collection, mailing list submission or payments.
