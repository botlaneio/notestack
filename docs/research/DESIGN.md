# Reference lock
Build target: enhanced https://www.fmpl.in/ homepage using Meta Astryx.
Leading source: existing Full Marks ecommerce structure and identity. White canvas, navy typography, red brand action, real book covers.
Craft references: Counter-Print for image-led book shelves and unboxed captions; Duolingo for approachable educational hierarchy and usable controls; Preply for clear outcome copy and spacious chapters. Reject their signature palettes, mascots, tiny controls, and serif marketing tropes. Existing brand and Astryx token roles take precedence.

Decision ledger:
- Page structure → FMPL extracted Shopify sections → retain campaign, categories, shelves, offers, resources and feedback.
- White/near-white content, navy ink, red primary action → FMPL logo and Astryx theme override → recognizable store identity.
- Cover-led shelves → Counter-Print → actual source assets with generous display area.
- Clear action hierarchy → Duolingo/Preply → one main action in hero, quiet secondary action.
- Components → Astryx neutral Theme, Button, TextInput, Badge → use actual library, not visual emulation.
- 4px spacing base; 8px controls and 16px major surfaces; 16px body; 56px desktop hero headline → Astryx composition plus responsive craft.
- No generated statistics, no fabricated verified reviews, no real transaction collection → source integrity.

Visual QA blocked until browser tool works. Static source checks and production build remain required.
